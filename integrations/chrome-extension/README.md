# Pick Me Now — 크롬 익스텐션 (사이드 패널)

회의·수업 중 브라우저 오른쪽 **사이드 패널**에서 Pick Me Now를 바로 여는 얇은 껍데기입니다.
게임 로직·화면은 전부 웹앱(`https://www.pickmenow.co.kr`)에서 로드하므로, 웹앱을 배포하면
이 익스텐션에도 자동으로 반영됩니다(익스텐션 파일을 다시 건드릴 필요 없음).

## 구성

| 파일 | 역할 |
| --- | --- |
| `manifest.json` | MV3 매니페스트. 툴바 액션 + 사이드 패널 등록 |
| `background.js` | 툴바 아이콘 클릭 시 사이드 패널 열기 |
| `panel.html` | `www.pickmenow.co.kr/embed` 를 패널에 꽉 채워 띄우는 iframe |

## 개발용 설치(심사 없이 바로 사용 — 데모/발표용)

1. Chrome 주소창에 `chrome://extensions` 입력
2. 오른쪽 위 **개발자 모드** 켜기
3. **압축해제된 확장 프로그램을 로드** 클릭
4. 이 폴더(`integrations/chrome-extension`) 선택
5. 툴바의 퍼즐 아이콘 → **Pick Me Now** 고정
6. 아이콘을 누르면 오른쪽 사이드 패널이 열리고, 게임을 고르면 방이 만들어집니다.
   참가자는 패널이 아니라 각자 폰에서 QR/링크로 입장합니다.

## 정식 배포(Chrome 웹 스토어)

- 개발자 대시보드에 zip 업로드 → 심사(보통 수일).
- 아이콘(16/32/48/128px PNG) 추가 필요 — 현재 개발용은 기본 아이콘으로 동작.
- 스토어 게시 후에도 게임 콘텐츠는 웹앱에서 오므로, **웹앱 배포만으로 최신 유지**됩니다.
  매니페스트/권한을 바꿀 때만 재패키징·재심사가 필요합니다.

## 참고

- 패널이 웹앱을 iframe으로 로드할 수 있는 건 웹앱이 프레임 차단 헤더
  (`X-Frame-Options` / CSP `frame-ancestors`)를 설정하지 않았기 때문입니다.
  추후 보안 강화를 위해 `frame-ancestors` 허용 목록을 둘 경우, 이 익스텐션 오리진
  (`chrome-extension://<확장 ID>`)을 목록에 추가해야 합니다.
